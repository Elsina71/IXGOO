# Kit di lavoro per Claude Code

Preso da https://github.com/thomascasali/claude-kb-workflow (licenza MIT, vedi LICENSE-claude-kb-workflow).

- `agents/` — frontend-dev, database, reviewer, security: Claude li sceglie da solo, oppure chiedili per nome ("usa l'agente reviewer").
- `skills/` — debugging-sistematico, verifica-prima-di-completare, brainstorming-design, schemi-errori-noti: partono da sole quando il compito corrisponde.

Per togliere un pezzo basta cancellare il suo file o la sua cartella.
